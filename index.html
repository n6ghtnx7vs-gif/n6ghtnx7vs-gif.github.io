Ne Panikuy Uploader

Личный инструмент автора YouTube-канала «НЕ ПАНИКУЙ» для загрузки собственных видео и просмотра статистики канала.

Политика конфиденциальности

Приложение использует YouTube API только для канала его владельца: загрузка видео, расписание публикаций, чтение статистики. Данные третьих лиц не собираются, не продаются и не передаются. Доступ можно отозвать в любой момент на странице myaccount.google.com/permissions.
